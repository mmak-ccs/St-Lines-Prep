# Equations of Straight Lines

Multiple-choice practice for the Secondary 4 HKDSE Mathematics topic **Equations of Straight Lines**.

The questions follow the style of HKDSE Paper 2. Wrong options are the mistakes that commonly appear on scripts: a reversed section ratio, a slope with the wrong sign, a horizontal line written as a vertical one, or an area ratio that was squared when the triangles only share a height. Each question has a hint and a full worked solution.

Topics:

- Slope and angle of inclination
- Point-slope, two-point, slope-intercept, intercept and general form
- Horizontal and vertical lines
- Parallel and perpendicular lines, including a family of lines through an intersection
- Distance between points, from a point to a line, and between parallel lines
- Mid-point formula, internal and external section formula
- Area and area ratios
- Centroid, orthocentre, circumcentre and incentre

The site is in English.

## Run it locally

```bash
npm install
npm run dev
```

Open the address printed by Next.js. To check the answers in the question bank:

```bash
npm run verify
```

## Put it on GitHub Pages

This repository includes `.github/workflows/pages.yml`. After the project is on GitHub:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Push to the `main` branch, or run the **Deploy GitHub Pages** workflow from the Actions tab.

The public address will be:

```text
https://<github-username>.github.io/<repository-name>/
```

If the repository is named `<username>.github.io`, the site is served from `https://<username>.github.io/` instead.

Classmates only need that link. No install step is required to use the finished site.
